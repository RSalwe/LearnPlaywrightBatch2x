# VS Code Keyboard Shortcuts - Mac

## General

| Action | Shortcut |
|--------|----------|
| Command Palette | `Cmd + Shift + P` |
| Quick Open (Go to File) | `Cmd + P` |
| New File | `Cmd + N` |
| Open File | `Cmd + O` |
| Save | `Cmd + S` |
| Save All | `Cmd + Option + S` |
| Close Editor | `Cmd + W` |
| Close Folder / Workspace | `Cmd + K` `F` |
| Close Window | `Cmd + Shift + W` |
| New Window | `Cmd + Shift + N` |
