# VS Code Keyboard Shortcuts - Windows

## General

| Action | Shortcut |
|--------|----------|
| Command Palette | `Ctrl + Shift + P` |
| Quick Open (Go to File) | `Ctrl + P` |
| New File | `Ctrl + N` |
| Open File | `Ctrl + O` |
| Save | `Ctrl + S` |
| Save All | `Ctrl + K` `S` |
| Close Editor | `Ctrl + W` |
| Close Folder / Workspace | `Ctrl + K` `F` |
| Close Window | `Ctrl + Shift + W` |
| New Window | `Ctrl + Shift + N` |
