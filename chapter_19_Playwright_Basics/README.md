# Chapter 19 — Playwright Basics

Browser automation fundamentals — launching Chromium and Firefox with Playwright.

## Files

| File | Topic | What you'll learn |
|------|-------|-------------------|
| `166_Launch_Browser.js` | Chromium | Launching Chromium, navigating to URLs |
| `167_Launch_Firefox.js` | Firefox | Launching Firefox, programmatic browser control |

## Requirements

```bash
npm install playwright
npx playwright install chromium firefox
```

## Run

```bash
node 166_Launch_Browser.js
```
