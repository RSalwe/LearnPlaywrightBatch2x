# Chapter 25 — OOP Interview Questions

Practice exercises covering the core OOP concepts from chapters 20–24: classes, objects, encapsulation, inheritance, polymorphism.

## Files

| File | Topic | What you'll practice |
|------|-------|---------------------|
| `EX1.js` | OOP practice 1 | Class design, constructor, methods |
| `EX2.js` | OOP practice 2 | Class relationships, object interaction |
| `EX3.js` | OOP practice 3 | Inheritance hierarchy |
| `EX4.js` | OOP practice 4 | Polymorphism and method overriding |

## Concept

These exercises test your understanding of:
- Defining classes with constructors and methods
- Using private fields for encapsulation
- Extending classes with `extends` and calling parent constructors with `super()`
- Overriding methods in child classes

## Run

```bash
node EX1.js
```
