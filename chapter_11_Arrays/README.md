# Chapter 11 — Arrays

Everything about arrays — creation, access, modification, searching, iteration, transformation, sorting, and checking.

## Files

| File | Topic | What you'll learn |
|------|-------|-------------------|
| `83_Arrays.js` | Array basics | Literal, mixed types, empty arrays |
| `84_Arrays.js` | Creating arrays | Literal, constructor, `Array.of`, `Array.from` |
| `85_Access_Array.js` | Accessing | Index access, `.at(-1)`, modifying |
| `86_Arrays_Adding_Remove.js` | push/pop/shift/unshift | Add/remove at ends |
| `87_Adding_Remove2.js` | splice | Insert, delete, replace at any index |
| `88_Real_Example.js` | Real examples | Practical array manipulations |
| `89_Searching.js` | Searching | `indexOf`, `includes`, `find`, `findIndex` |
| `90_Iterate.js` | Iteration | `for`, `for...of`, `forEach`, `for...in` |
| `91_Tranform_Array.js` | Transform | `map`, `filter`, `reduce`, `flat` |
| `92_Arrays_Sorting.js` | Sorting | `sort()` numeric comparator |
| `93_Array_slicing.js` | slice | Non-mutating subarray extraction |
| `94_Concat_Array.js` | Concat | `concat()`, spread `[...a, ...b]` |
| `95_Array_Checking.js` | Checking | `Array.isArray`, `every`, `some` |

## Run

```bash
node 83_Arrays.js
```
