# Chapter 04 — Variables, Scope & Hoisting

Deep dive into `var`, `let`, `const` — their scoping rules and hoisting behavior.

## Files

| File | Topic | What you'll learn |
|------|-------|-------------------|
| `09_var_let_const.js` | Overview | `var` vs `let` vs `const` comparison |
| `10_functions.js` | Functions | Defining and calling functions |
| `11_var_explained.js` | var explained | `var` — function-scoped, redeclarable, hoisted |
| `12_let_people_love.js` | let explained | `let` — block-scoped, no redeclaration |
| `13_const_explained.js` | const explained | `const` — block-scoped, must initialize |
| `14_var_functionscope.js` | var scope | Function scope behavior with `var` |
| `15_let_scope.js` | let scope | Block scope behavior with `let` |
| `16_Hoisting.js` | Hoisting intro | Variable hoisting to `undefined` |
| `17_hoisting_function.js` | Function hoisting | Function declarations are hoisted entirely |
| `18_let_hoisting.js` | let hoisting | Temporal Dead Zone (TDZ) with `let` |
| `19_let_hoisting_block.js` | let in blocks | TDZ behavior inside block scopes |
| `20_const_hoisting.js` | const hoisting | TDZ with `const` |
| `21_Jr_QA.js` | Junior QA | Common QA interview concepts |
