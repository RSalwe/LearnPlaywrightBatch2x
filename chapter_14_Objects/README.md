# Chapter 14 — Objects

Objects in JavaScript — creation, property access, destructuring, spread, getters/setters, and real-world examples.

## Files

| File | Topic | What you'll learn |
|------|-------|-------------------|
| `124_Objects.js` | Object basics | Key-value pairs, reference types |
| `125_Objects2.js` | Objects deep dive | Dot/bracket notation, copy by reference |
| `126_Objects_Creation.js` | Creation | Object creation, reference equality |
| `127_Objects_REAL.js` | Real objects | Adding/deleting properties |
| `128_Primitive_Ref.js` | Primitive vs ref | Copy by value vs copy by reference |
| `129_Objects_Example.js` | JS vs JSON | JSON vs JS object syntax |
| `130.IQ.js` | IQ | Dynamic property access, descriptors |
| `131_Object_Fn.js` | Object methods | Functions inside objects |
| `132_Object_Deconstruct.js` | Destructuring | Extract, rename, defaults, nested |
| `133_Spread.js` | Spread | `...` spread with objects |
| `134_Object_GET_SET_Methods.js` | Getters/setters | `get` and `set` keywords |
| `135_IQ.js` | IQ | `Object.keys()`, `values()`, `entries()` |
| `136_Objects_Real.js` | Real-world | Config objects, API responses |

## Run

```bash
node 124_Objects.js
```
